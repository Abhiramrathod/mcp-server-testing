Quick Installation

Get started in minutes

<dependency>
  <groupId>io.github.abhiramrathod</groupId>
  <artifactId>mcp-test-api</artifactId>
  <version>1.0.15</version>
  <scope>test</scope>
</dependency>
testImplementation 'io.github.abhiramrathod:mcp-test-api:1.0.15'
Only add mcp-test-api — all other modules are included transitively.

Your First Test

import mcp.toolkit.testing.framework.api.*;
import mcp.toolkit.testing.framework.api.model.*;

public class MyFirstTest {
  @Test
  public void testMcpServer() {
    McpClient client = McpClient.connectTo("http://localhost:8080")
        .config(McpClientConfig.builder()
            .timeout(Duration.ofSeconds(30))
            .build())
        .initializeOnBuild()
        .build();

    McpToolResult result = client.tools()
        .callTool("calculator", Map.of("operation", "add", "a", 5, "b", 3))
        .assertSuccess()
        .assertTextContains("8");

    client.exchanges().assertAverageLatencyBelow(McpMethod.TOOLS_CALL, 500);
    client.close();
  }
}

Configuration

Control client behavior via McpClientConfig

Key Options

  • timeout (Duration) — request timeout for connections and RPC calls. Default: 10s.
  • protocolVersion (String) — MCP protocol version. Default: 2024-11-05.
  • SSE path — default SSE endpoint: /sse.
  • Streamable HTTP path — default endpoint: /mcp.
McpClientConfig config = McpClientConfig.builder()
    .timeout(Duration.ofSeconds(30))
    .protocolVersion("2024-11-05")
    .build();

McpClient client = McpClient.connectTo("http://localhost:8080")
    .config(config)
    .build();
Use .streamableHttp() on the builder for Streamable HTTP transport instead of SSE.

Modules

Six specialized modules with clean separation of concerns

mcp-test-api

Coordinates: io.github.abhiramrathod:mcp-test-api

Purpose: Public API — import this artifact in your test scope.

Key classes: McpClient, McpClientConfig, ToolsClient, ResourcesClient, PromptsClient, domain models, assertions.

mcp-test-client

Coordinates: io.github.abhiramrathod:mcp-test-client

Purpose: Internal client implementation. Handles initialization, RPC, and component wiring.

Key classes: McpTestClient, tool/resource/prompt directories, exchange tracking.

mcp-test-transport

Coordinates: io.github.abhiramrathod:mcp-test-transport

Purpose: Transport implementations — SSE and Streamable HTTP.

Key classes: McpSseTransport, McpStreamableHttpTransport.

Transport is pluggable via McpTransport interface.

mcp-test-core

Coordinates: io.github.abhiramrathod:mcp-test-core

Purpose: Shared utilities — JSON codec, constants, validation helpers.

Key packages: mcp.toolkit.testing.framework.core

mcp-test-interfaces

Coordinates: io.github.abhiramrathod:mcp-test-interfaces

Purpose: Core SPI — the McpTransport interface for custom transport implementations.

mcp-test-examples

Purpose: Example tests demonstrating tools, resources, prompts, performance monitoring, and full integration workflows.

Run: mvn -pl mcp-test-examples test

Build: mvn -T 1C clean install  ·  Javadocs: mvn javadoc:jar  ·  Publishing: Configured for Sonatype OSSRH / Maven Central.

View API Javadocs (if generated).

Core Capabilities

Comprehensive testing for all MCP features

Tools Testing

Discover and invoke MCP tools with strongly-typed results and fluent assertions.

List<McpTool> tools = client.tools().listTools();

McpToolResult result = client.tools()
    .callTool("calculator", Map.of("op", "add", "a", 5, "b", 3))
    .assertSuccess()
    .assertTextContains("8");

Resources Testing

List and read MCP resources with content validation.

List<McpResource> resources = client.resources().listResources();

McpResourceContent content = client.resources()
    .readResource("file://config.json")
    .assertNotEmpty();

Prompts Testing

Retrieve and inspect MCP prompts with argument validation.

List<McpPrompt> prompts = client.prompts().listPrompts();

McpPromptResult prompt = client.prompts()
    .getPrompt("translate", Map.of("lang", "en"))
    .assertNotEmpty();

Performance Monitoring

Track every JSON-RPC exchange and assert on latency thresholds.

client.exchanges()
    .assertAverageLatencyBelow(McpMethod.TOOLS_CALL, 500);

long p99 = client.exchanges()
    .latencyPercentile(McpMethod.TOOLS_CALL, 99);

Core mcp-test-interfaces / mcp-test-core
Users only import mcp-test-api — all other modules are internal dependencies
